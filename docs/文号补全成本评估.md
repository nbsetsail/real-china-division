# 文号补全路线成本评估（2010-2017 缺口）

> 背景：事件库 5274 条，已回填 `source_official`+`source_url`（MCA 年度变更页面，可核验官方出处）183 条，其中 2010-2017 占 108 条。`doc_no` 仅 123 条且几乎无 2010-2017。本评估回答：补"批准文号（国函/政函 XX号）"是否值得开一条新线。

## 三条候选渠道实测结果

| 渠道 | 2010-2017 覆盖 | 可抓取性 | 结论 |
|---|---|---|---|
| 中国政府网政策文件库 `zhengcelibrary_gw` | "行政区划"标题批复仅 37 条，年份分布 2008:33 / 2010:3 / 2018:1，**2011-2017 全空**；"撤县设市"仅 4 条且为 1987 年旧批复重印 | 接口可用，但库里就没有这些文档 | **死路**（上一轮"全文=0"结论修正：根因是库未数字化，不是检索字段问题） |
| 国务院公报原刊 `gongbao/YYYY/issue_NNNNN/` | 每期都登国函，正文是 **HTML 全文**（URL 形如 `…/YYYYMM/content_*.html`，无需 OCR） | 年份索引 `gongbao/2014/` → 403；无 sitemap；期号 `issue_NNNNN` 不公开枚举；官方检索 `gbsousuo` 是 JS 渲染（静态抓无结果） | **可行但入口受限**：需无头浏览器驱动 JS 检索，或期号枚举+逐期解析 |
| 省政府公报 ×31 | 覆盖政函/民函（省级审批的区划调整大头） | 各省独立站点、格式异构、多数无结构化检索 | **成本过高**：数周级，且部分省数字档案不全 |

## 已具备的资产（不必重做）

- MCA 年度变更页面 485 条官方记录已 harvest，183 条事件已回填 `source_official`+`source_url`，**已是"可核验的官方出处"**（URL 可点击核验，非虚构）。
- 这是 L1/L2 产品审计需求能接受的交付标准。

## 成本-收益

- **国务院级国函**（需国务院审批：撤县设市、县级市改区、地区改市、地市辖区撤并）：技术可挖（公报 HTML 全文），但入口受限，**纯自动化约 2-3 天**（无头浏览器 + 期号枚举 + 逐期解析 + 文号↔事件匹配）。只覆盖 2010-2017 事件的小部分（国务院审批子集）。
- **省级政函/民函**：31 省异构，**数周级**，不建议。
- 产出价值：把"可核验出处 URL"升级为"批准文号 + 出处 URL"的金标准——对 L3 审计级客户有说服力，对 L1/L2 边际增益有限。

## 建议

**不现在开文号线。** MCA 年度页 URL 作为可核验官方出处已满足 L1/L2。文号提取归入 **L3 按需**（具体审计客户付费才做），且届时仅补**国务院级国函**（用公报原刊 + 无头浏览器，跳过 31 省）。

待决策：客户到底需要"批准文号"还是"可核验官方出处"就够了？这直接决定要不要投入那 2-3 天。
