# 中国行政区划数据集 · 持续更新版

> 省地县乡四级民政口径区划码 + 乡镇街道全量 + **1980-2026 变更事件库（5,195 条）** + 别名映射词典，
> 附一个自包含的 Python 解析引擎。零强制依赖。

本仓库以事件驱动管线维持数据持续更新：官方渠道怎么变，获取方式就怎么跟着变。
每一版数据带 tag 与校验和，每一条变更可追溯到事件。

## 快速开始

```bash
git clone https://github.com/nbsetsail/real-china-division.git
cd real-china-division
# 引擎零依赖，可选启用拼音纠错：
pip install pypinyin
```

```python
from engine import resolve, resolve_by_code

resolve("襄樊市樊城区")        # 历史名 → {'status': 'resolve', 'result': '湖北省-襄阳市-樊城区', ...}
resolve("通州区")              # 同名歧义 → 输出候选集，不猜测
resolve("雄安新区容城县")      # 非民政建制 → 正确归属保定市
resolve("苏州工业园区")        # 非正式区划 → 诚实标注特殊口径
resolve("深镇")                # 错字 → 拼音纠错 → 广东省-深圳市（需可选依赖 pypinyin）
resolve_by_code("510124")     # 历史码回溯 → 四川省-成都市-郫都区，2016 年撤县设区
```

以上示例即真实输出，可直接复现。变更明细见 [CHANGELOG.md](CHANGELOG.md)。

## 一、维护方式：事件驱动管线

| 信息流 | 渠道 | 角色 |
|---|---|---|
| 底库 | 国家地名信息库行政区划接口（每年 1 月年度版 + 年内日更新） | 权威基线 |
| 事件流 | 国务院 / 民政部 / 省民政厅区划变更批复公告（带文号） | 增量与溯源 |
| 地名流 | 地名信息库地名搜索接口（村级实体、历史沿革） | 扩容与别名原料 |
| 哨兵 | 地图 API 行政区划 | 变更敏感信号 |

数据随版本发布（tag + 校验和），每一条变更可追溯到事件。**持续更新是本仓库的首要承诺。**

## 二、数据内容

| 文件 | 规模 | 说明 |
|---|---|---|
| `data/divisions_v1.json` | 33 省 / 341 地级 / 2847 县级 | 民政口径，官方 12 位码，年度版 2025-12-31 |
| `data/townships_v1.json` | 2,827 县级 / 38,749 乡镇街道 | 含区县归属 |
| `data/historical_changes_v1.json` | **5,195 条变更事件（1980-2026）** | 撤县设区 152 / 撤县设市 390 / 撤地设市 122 / 更名 879 / 同名改码 2221 / 划转 / 撤销 / 新设；1980-2020 由官方代码簿逐年差分，2021+ 由人工依据批复公告整理（带文号） |
| `data/*.csv` | 同上平行格式 | 通用消费（divisions / townships / change_events） |
| `aliases.json` | 人工整理别名词典 | 历史名 / 古称 / 地标 / 简称 / 歧义 / 特殊口径，每条带来源 |

### 数据字典（核心字段）

- **divisions**：`{省: {code, cities: {市: {code, counties: {县: 12位码}}}}}`；CSV 版 `code,name,level,parent_code`
- **townships**：`{县级12位码: {county: 县名, townships: {乡镇名: 12位码}}}`
- **change_events**：每条含 `year / type / level / old(code,name,path) / new(code,name,path) / doc_no / source`；`doc_no` 为增量回填字段

> **编码说明**：CSV 为 UTF-8 with BOM——Excel/WPS 双击即可正确显示中文。pandas 读取请用 `pd.read_csv(..., encoding="utf-8-sig")`。

## 三、解析引擎（engine.py）

自包含单文件，零强制依赖；可选安装 `pypinyin` 启用拼音错字纠错（未安装时该能力降级为不解析，其余功能不受影响）。

引擎特性：别名/历史名解析（由事件库自动生成 **511 条**映射，随版本更新再生）、同名歧义输出候选集、
开发区/新区/兵团等特殊口径诚实标注、拼音错字纠错（可选）、编码直查与历史码回溯、
不留存架构（纯函数无状态）。

## 四、口径诚实声明（Don't trust, verify）

1. **双口径差异**：统计口径的村级「城乡分类代码」是统计局专属，自 2024-10 起无现行公开渠道。
   本数据集**不提供、不编造**；村级实体以民政地名口径发布。
2. **村级码制**：行政村/社区不是一级建制，其编码为民政地名口径的 **20 位地名标准码**（前 12 位对应所属县级区划），与上级四级的 12 位建制码是两套体系。
3. **早期噪声**：1984 年前全国代码多次重编，事件库中该时期存在代码串扰噪声，重要结论请以民政批复原文为准。
4. **非正式建制**：开发区/新区/园区在民政口径中不是正式建制，引擎按「特殊口径」标注而非硬归。
5. **未覆盖县域**：金门、三沙市西沙区/南沙区、西藏岗巴县/噶尔县、云南大姚县、新疆和安县等 7 个特殊县域暂无村级数据。
