# 中国行政区划数据集 · 持续更新版

> 省地县乡四级民政口径区划码 + 乡镇街道全量 + **1980-2026 变更事件库（5,274 条）** + 别名映射词典，
> 附一个自包含的 Python 解析引擎。零强制依赖。

本仓库以事件驱动管线维持数据持续更新：官方渠道怎么变，获取方式就怎么跟着变。
每一版数据带 tag 与校验和。

**本仓库是社区版（永久免费开源、可商用）**。免费能力的边界见 [FEATURES.md](FEATURES.md)。

## 快速开始

```bash
git clone https://github.com/nbsetsail/real-china-division.git
cd real-china-division
# 引擎零依赖，可选启用拼音纠错：
pip install pypinyin
```

```python
from engine import resolve, resolve_by_code

resolve("襄樊市樊城区")        # 历史名 → {'status': 'resolve', 'result': '湖北省-襄阳市-樊城区', ...}
resolve("通州区")              # 同名歧义 → 输出候选集，不猜测
resolve("雄安新区容城县")      # 非民政建制 → 正确归属保定市
resolve("苏州工业园区")        # 非正式区划 → 诚实标注特殊口径
resolve("深镇")                # 错字 → 拼音纠错 → 广东省-深圳市（需可选依赖 pypinyin）
resolve_by_code("510124")     # 历史码回溯 → 四川省-成都市-郫都区，2016 年撤县设区
```

以上示例即真实输出，可直接复现。变更明细见 [CHANGELOG.md](CHANGELOG.md)。

## 一、维护方式：事件驱动管线

| 信息流 | 渠道 | 角色 |
|---|---|---|
| 底库 | 国家地名信息库行政区划接口（每年 1 月年度版 + 年内日更新） | 权威基线 |
| 事件流 | 国务院 / 民政部 / 省民政厅区划变更批复公告 | 增量 |
| 地名流 | 地名信息库地名搜索接口（村级实体、历史沿革） | 村级数据源 |

数据随版本发布（tag + 校验和），每条变更对应一次真实区划调整。**持续更新是本仓库的首要承诺。**

## 二、数据内容

| 文件 | 规模 | 说明 |
|---|---|---|
| `data/divisions_v1.json` | **34 省级**（31 大陆省级 + 香港 + 澳门 + 台湾）/ 341 地级 / 2847 县级 | 民政口径，官方 12 位码，年度版 2025-12-31。台湾省为国家地名信息库未收录、按 GB/T 2260 补录的省级条目（码 710000000000，仅省级、下辖未列），来源见文件内 `meta.patched` |
| `data/townships_v1.json` | 2,827 县级 / 38,749 乡镇街道 | 含区县归属 |
| `data/historical_changes_v1.json` | **5,274 条变更事件（1980-2026）** | 同名改码 2221 / 新设 727 / 码位改派 623 / 撤销 612 / 撤县设市 396 / 更名 264 / 撤县设区 153 / 撤地设市 122 / 撤市设区 71 / 区划调整 57 / 划转 16 / 驻地迁移 9 / 撤区设区 2 / 撤旗设区 1；1980-2020 由 GB/T 2260 官方口径逐年快照差分，2021+ 增量由民政部区划地名网《县级以上行政区划变更情况》年度官方页（1999-2026，逐条带省级政府公告出处）+ 人工依据批复公告整理。其中 183 条附民政部年度变更页链接（`source_official` + `source_url`），`doc_no` 批准文号仅 123 条、未做全量补录。`码位改派` 表示同一区划码在不同年份指向了不同实体（码位被重新分配），由逐年快照差分产生，**不构成行政区划沿革**，故与 `更名` 分列 |
| `data/*.csv` | 同上平行格式 | 通用消费（divisions / townships / change_events）；村级 `villages.csv`（46MB）体积过大不入库，取全量数据请到 GitHub Release 下载按版本打包的 `real-china-division-data-<版本>.tar.gz`，解压得单一顶层目录 |
| `aliases.json` | 人工整理别名词典 | 历史名 / 古称 / 地标 / 简称 / 歧义 / 特殊口径，每条带来源 |

### 数据字典（核心字段）

- **divisions**：`{省: {code, cities: {市: {code, counties: {县: 12位码}}}}}`；CSV 版 `code,name,level,parent_code`
- **townships**：`{县级12位码: {county: 县名, townships: {乡镇名: 12位码}}}`
- **change_events**：每条含 `year / type / level / old(code,name,path) / new(code,name,path) / doc_no / source / source_official / source_url`；`source` 为整理来源说明，`source_official` + `source_url` 为民政部年度变更页链接（仅 183 条回填），`doc_no` 为批准文号（仅 123 条）；**CSV 版与 JSON 版字段一致**

> **编码说明**：CSV 为 UTF-8 with BOM——Excel/WPS 双击即可正确显示中文。pandas 读取请用 `pd.read_csv(..., encoding="utf-8-sig")`。

## 三、解析引擎（engine.py）

自包含单文件，零强制依赖；可选安装 `pypinyin` 启用拼音错字纠错（未安装时该能力降级为不解析，其余功能不受影响）。

引擎特性：别名/历史名解析（由事件库自动生成 **843 条**映射，随版本更新再生）、同名歧义输出候选集、
开发区/新区/兵团等特殊口径诚实标注、拼音错字纠错（可选）、编码直查与历史码回溯、
不留存架构（纯函数无状态）。

## 四、口径诚实声明（Don't trust, verify）

1. **双口径差异**：统计口径的村级「城乡分类代码」是统计局专属，自 2024-10 起无现行公开渠道。
   本数据集**不提供、不编造**；村级实体以民政地名口径发布。
2. **村级码制**：行政村/社区不是一级建制，其编码为民政地名口径的 **20 位地名标准码**（前 12 位对应所属县级区划），与上级四级的 12 位建制码是两套体系。
3. **早期噪声**：1984 年前全国代码多次重编，事件库中该时期存在代码串扰噪声，重要结论请以民政批复原文为准。
4. **非正式建制**：开发区/新区/园区在民政口径中不是正式建制，引擎按「特殊口径」标注而非硬归。
5. **未覆盖县域**：金门、三沙市西沙区/南沙区、西藏岗巴县/噶尔县、云南大姚县、新疆和安县等 7 个特殊县域暂无村级数据。
